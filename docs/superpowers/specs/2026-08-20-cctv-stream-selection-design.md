# CCTV 主/子码流选择设计

## 目标

在手动添加 CCTV 摄像机页面中，在“摄像机型号/品牌”一行下面增加“码流类型”一行。用户可像切换品牌一样，通过左右按钮选择主码流或子码流。

本功能只决定室内机连接摄像机的 RTSP 通道，不修改摄像机内部的视频编码、分辨率、帧率或码率配置。

## 界面

- 在品牌行下方增加“码流类型”行。
- 选项为“主码流”和“子码流”。
- 新添加海康或大华摄像机时默认选择“主码流”。
- 使用现有品牌行相同的左右箭头和按压效果。
- IP、账号、密码三行依次向下移动。
- 不增加分辨率弹窗和齿轮按钮。

## RTSP 地址规则

注册或预览前，根据品牌和码流类型生成 RTSP URL：

| 品牌 | 主码流 | 子码流 |
| --- | --- | --- |
| 海康 | `/Streaming/Channels/1` | `/Streaming/Channels/2` |
| 大华 | `/cam/realmonitor?channel=1&subtype=0` | `/cam/realmonitor?channel=1&subtype=1` |

海康主码流继续使用当前工程已经验证的 `/Streaming/Channels/1`，避免改变现有连接行为。

## 保存与兼容

- 码流选择直接体现在最终保存的 RTSP URL 中，因此现有 `camera_info.url` 已能持久化该选择。
- 不修改 `camera_info` 和 `user_data_info` 结构，避免升级后因结构大小和字段偏移变化导致用户配置被重置或错位。
- 新添加设备默认生成主码流 URL。
- 用户选择子码流后，保存对应的子码流 URL；设备重启后继续使用该 URL。
- 已注册的旧设备保留原 URL，不自动转换：旧海康保持原主码流，旧大华若原来是 `subtype=1` 则继续使用子码流。

## 代码范围

- `src/layout/layout_setting_ipc.c`

  - 集中生成品牌和码流对应的 RTSP URL。

- `src/layout/layout_define.h`

  - 验证四种品牌与码流组合生成正确 URL。
  - 验证默认选择为主码流。

## 验收标准

1. 手动添加页面在品牌下方显示码流类型。
2. 海康和大华新设备均默认显示主码流。
3. 左右按钮可以在主码流和子码流之间切换。
4. 海康四种操作中的主、子选择生成对应通道 URL。
5. 大华主码流使用 `subtype=0`，子码流使用 `subtype=1`。
6. 注册后重启设备，摄像机仍使用注册时选择的码流。
7. 已注册摄像机的原有 URL 不被升级程序自动修改。
