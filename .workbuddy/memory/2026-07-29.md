## 涂鸦占线逻辑重构 — 室内机音频功能隔离

**需求**：手机端Tuya使用时，室内机不再进入占线状态，可正常使用非音频功能，但阻止访问音频相关界面/功能。

**实现方案**：
1. 新增 `tuya_audio_occupied_check()` 统一检查函数（`layout_define.h` + `layout_define.c`）
   - 判断条件：`tuya_client_num_get() > 0 || tuya_monitor_state_get()`
   - 提示信息：`text_str(STR_DEVICE_BUSY)` → "设备繁忙"，持续2000ms

2. 放开占线锁定（移除 `tuya_monitor_state_get()`）：
   - `layout_standby.c`: standby_click_up, standby_time_touch_up, motion_back_btn_up
   - `layout_device_busy.c`: motion_busy_detect_task 退出条件

3. 音频入口加保护（添加 `tuya_audio_occupied_check()`）：
   - `layout_home.c`: 监控、对讲、媒体、事件 → 4处
   - `layout_standby.c`: 待机底部菜单(监控/呼叫/留言/移动侦测) → 4处
   - `layout_monitor_1.c`: 门口机1/2、摄像头1/2 → 4处
   - `layout_media.c`: 音乐入口 → 1处
   - `layout_call.c`: 来电事件处理(extern + inside) → 2处
   - `layout_interphone.c`: 内线呼入事件处理(extern + inside) → 2处

4. 保留的检查（不修改）：
   - `motion_detect_func`: 移动侦测仍是音频功能，保留tuya检查
   - `motion_timer_task`: 内部清理逻辑，保留
   - `layout_monitor.c`: 监控页内部防御检查，保留

**修改文件清单**（共10个）：
- `src/layout/layout_define.h`

- `src/layout/layout_home.c`

## 补充：禁止Tuya监控时室内机进入监控界面

**需求**：手机端进入Tuya监控时，室内机不再跳转到监控覆盖层界面，保持当前页面。

**修改**：
- `layout_standby.c` `tuya_event_motion_proc` → `TUYA_EVENT_MONITOR_ENTER` case
  - 移除：`motion_2_head_create()`、`standby_obj_disable()`、`standby_black_screen()`、`lv_obj_set_click()`、`fb_background_enable(false)`、隐藏back_btn
  - 保留：`record_video_stop(true)`、`gui_draw_area_set_2()`、`tuya_channel_valid_report()`、`monitor_enter_way_set(MONITOR_ENTER_TUYA)`
  - 效果：仅设置状态标志，不画UI、不锁屏、不改变当前页面

- `layout_monitor.c` `tuya_event_extern_proc` → `TUYA_EVENT_MONITOR_ENTER` case
  - 新增：`current_layout_get() == &layout_standby || &layout_home` 时直接 break，不执行 `goto_layout(pLAYOUT(monitor))`
  - 根因：正常待机时活跃的 Tuya 事件处理器是 `tuya_event_extern_proc`（不是 `tuya_event_motion_proc`），其 MONITOR_ENTER 处理会 `goto_layout(monitor)` 把室内机拽进监控页

## 补充2：Tuya监控时室内机不跳页+视频管道保留

**问题1**：直接 return 监控页 ENTER 导致 Tuya 视频断流。
**问题2**：`monitor_open()` 在 MONITOR_ENTER_TUYA 时填全屏黑色，抹掉待机背景。
**问题3**：只限制了 standby/home，其他页面仍会跳监控页。

**最终方案**：
- `layout_monitor.c` `tuya_event_extern_proc` → `TUYA_EVENT_MONITOR_ENTER` case
  - 移除布局条件判断，**所有页面**统一不跳页
  - `monitor_open()` 在 `monitor_enter_way_set(TUYA)` 之前调用 → 不填黑屏
  - `audio_talk_open()` 前检查 `get_outdoor_talk_state()`：门口机通话中跳过音频 → Tuya SDK 自动返回 `TRANS_EVENT_SPEAKER_ISUSED`
- 监控页 ENTER 和 `motion_2_head_create()` 恢复原样（撤销 guard）
